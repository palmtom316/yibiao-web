# 尚未满足的真实验收条件

这是审核计划中剩余的实际验收，不是新增审批流程。没有收到批准的真实服务配置和脱敏招标样本，故不得擅自把资料发到任意服务；当前实现已完成本地/数据库/Linux/合成浏览器验证。

## 需要部署方提供

- 模型网关最终 URL、模型名、凭据的受保护配置位置；允许的项目/共享数据范围。配置完成后仍应由管理员设置部署白名单和相应处理策略。
- MinerU 最终端点、接口类型（v4/agent）、凭据配置位置；含扫描/表格/图片的脱敏样本。
- 一份脱敏招标和配套公司证照、人员证书、类似业绩原件/叙述在本机的路径。现有“合成”样本不能改名当作真实脱敏验收。

不用把密钥粘贴进对话、报告或命令行。配置 GET/PUT 响应只会给 configured 和空密钥；空输入保留原值，显式 clear_secrets 才清除。

## 取得输入后的执行顺序

1. 在新的隔离项目导入样本，记录原件 SHA-256、尺寸/页数、解析器与图片位置。先拒绝外部策略测试，确认实际外发次数为 0；批准指定端点/域后才真实请求。
2. 真实模型完成分析、目录 V2 每阶段人工确认、全局事实、正文、Word；缺 helper/Word 原件时核对普通目录降级。记录请求次数、阶段耗时和人工调整，不记录密钥或完整原文日志。
3. MinerU 至少完成一次真实扫描 OCR，检查文字、表格、图片及原文定位；失败保留原件并显示质量警告。mock 401/429/坏 ZIP 已覆盖，仍不替代该项。
4. 用该脱敏招标分别做技术与商务抽取，确认技术目录未混入商务项；人工修订后重抽保持；切换标段/日期/原件必须复核。
5. 候选逐条件人工确认、不可变快照、技术章引用、Word/ZIP，逐文件核对 hash 与 manifest；未确认/缺件/撤销应阻止正式包，权限撤销后不能下载。
6. 真实模型规划并生成 HTML/Mermaid（及获批生图服务的可选图），人工核对事实、重试和 Word 图像，记录峰值资源。
7. 更新对应 BLOCKED 报告和 STATUS。只有适用 A01～A10、源码入口/镜像版本及发布环境条件均满足，才讨论生产发布；生产发布仍需另行明确授权。
