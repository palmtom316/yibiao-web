# 功能清单与模块说明

本文描述改造分支的实现范围；验收与尚缺的外部条件见 [实施状态](implementation/STATUS.md)。尚未发布生产。第一期单公司，多人各自管理项目，项目所有者与管理员可访问，不提供普通用户同项目协同编辑。

## 工作台与技术标

- 技术方案、已有方案扩写、招标分标段、全局事实、正文、响应与偏离表及 Word 导出继续保留。
- 原件先保存，解析有独立版本、文件 hash、图片清单与警告；支持授权预览、重解析和图片导出。旧 Markdown 记录仍可浏览，需要原件时提示重新上传。
- Pi 可用时提供目录 V2：选择技术一级目录、确认评分分支、分配字数/小节、处理数量差异及最终审核；每阶段保存检查点。缺服务时使用普通目录路径。原方案扩写保留既有流程。
- 手工修改章节自动保护。显式选择已确认业绩/团队加入目标章节后，金额、证号、人名由固定引用版本直接渲染；不能通过模型或普通编辑改写引用块。
- 后台任务关页继续，SSE 重连取得权威状态。服务重启后正文可继续，其余任务明确中断后重试；目录 V2 重试可复用完成阶段和确认。

## 公司资料与业绩

- 公司/工具资料保留原件；公司证照和人员证书补齐证号、类别、等级、签发方、生效日期、明确有效期类型。空到期日表示未知，不自动认定永久有效。
- 人员是一人多证；证书、原件和岗位分别维护。公司/人员证照有 30 天到期列表。
- 业绩档案记录业主、地点、十进制金额、时间、项目类型及叙述，关联多份公司原件、多份知识/条目和多个团队岗位。默认不允许对外引用。
- 资料与业绩维护使用版本冲突校验和审计。归档保留原件与引用；物理删除须先解除业绩关联。撤销引用许可会阻止新的生成/交付，历史文件不改写。
- 扁平旧人员库停止新增/修改，保留只读定位；迁移脚本提供 dry-run、人工持有人映射、hash 核对和重复执行保护。

## 商务响应与交付

- 商务要求人工录入及独立抽取，记录原文位置、标段、来源 hash、核验日期和人工修订。重新抽取不会覆盖人工修改。
- 关键词只产生候选。逐项显示数值、日期、等级、角色及未知项，只有人工核验才能确认满足；关键未知/不满足项不能确认为满足。
- 确认时复制结构化字段、许可叙述、原件和知识图片到项目引用版本；来源变更、归档或删除不改写该副本。历史页显示来源变更/缺失及引用撤销。
- 不可变响应版本可导出清单 Word、排序原件 ZIP 和 SHA-256 manifest；中文同名文件不覆盖。缺件或未确认阻止正式包，可另导出有明显标记的缺项草稿。
- 不提供最终商务得分引擎，也不把任意 PDF 自动转成整套可编辑商务投标书。

## 解析、搜索与可选增强

- 知识搜索在 PostgreSQL 分页，每页固定 100 条；覆盖文件名与条目文本，稳定排序、越尾回落；未完成/归档资料不作为可引用结果。
- MinerU 支持受控上传、轮询、下载、安全解压、有限重试和取消；扫描件没有可用 OCR 时明确提示需 OCR/人工处理。真实 MinerU 验收仍需批准端点和凭据。
- 可选增强镜像带 Linux .NET 10 OpenXmlHelper：章节抽取、表格/页眉/页脚保留、待填字段扫描、建议/人工分类及 Word 内容控件。签字盖章必须人工填写。PDF-only、无原件或缺工具时显示“未抽取模板”。
- 配图沿用固定上游规划和修复流程；HTML/Mermaid 在离线 Chromium 渲染并保存项目资产，可预览/导出，单图失败不清正文。模型图仍须人工核对事实，公网生图必须通过同一出口授权。

## 管理、权限与部署

- 保留导出格式模板、提示词、使用文档、FAQ、审批/禁用用户、主题与品牌设置。
- 所有配置 GET/PUT 都脱敏，空密钥保留、显式操作清除。Pi 只有受限文件、JSON 校验和提问工具，无任意 bash。OpenCode 未适配路径明确禁用。
- 模型/OCR/生图使用部署端点白名单；项目和共享域默认不允许外部处理。含共享资料的项目必须同时满足两域策略；每次发送重新检查当前权限。
- Docker Compose 提供 nginx/app/migrate/PostgreSQL，单 app、单 Node 进程、只对外开放 443。基础镜像不依赖 .NET/Chromium。
- migrations 支持空库与旧 db-push 库 baseline；初始化只补缺失管理员/提示词/文档，不重置已有内容。内置文档更新另有版本化报告。
- 同批备份先停止 app 后台写入，再打包数据库、/data 与受保护配置；恢复拒绝非空目标并逐文件核对 hash。
